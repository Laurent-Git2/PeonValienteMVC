# PEÓN VALIENTE — PHRASES & DESIGNS

Base créative des phrases, slogans et concepts visuels de Peón Valiente.

Marché prioritaire : Espagne.
Langues principales : espagnol / français.

---

# 1. RÈGLES

## Statuts

- 💡 Idée : concept brut.
- 🟡 À tester : phrase intéressante à retravailler ou tester.
- ⭐ Candidat : concept suffisamment fort pour envisager un design.
- ✅ Validé : concept retenu pour création.
- 🎨 Design : création graphique en cours.
- 🖨️ POD : fichier prêt pour impression.
- 🛒 Publié : produit mis en vente.

## Principe

Ce document conserve les idées créatives, y compris les variantes.

Le CRUD `Ideas` contient principalement les concepts sélectionnés pour être réellement travaillés.

# 2. COLLECTION — BLITZ

## BL001 — El reloj

### Espagnol

**En blitz, el reloj es una pieza más.**

### Français

**En blitz, la pendule est une pièce de plus.**

### Statut

✅ VALIDÉ

### Potentiel

10/10

### Concept visuel

Une pendule d'échecs devient symboliquement une pièce supplémentaire sur l'échiquier.

Ambiance :
- tension ;
- pression du temps ;
- échiquier ;
- pendule au centre ;
- composition claire et imprimable.

Le visuel ne doit pas être excessivement photoréaliste ou complexe pour conserver une bonne impression POD.

### Déclinaisons prévues

- T-shirt noir
- T-shirt clair
- Sweat
- Mug
- ES prioritaire
- FR secondaire

**Si tu vois le sacrifice, c'est déjà trop tard.**

⭐ CANDIDAT PRIORITAIRE

# 5. COLLECTION — ELO / PSICOLOGÍA

## EL001 — 1200 / 1800

### ES

**A 1200 Elo lo ves todo.  
A 1800 sigues sin ver nada.**

### FR

**À 1200 Elo, tu vois tout.  
À 1800, tu ne vois toujours rien.**

### Statut

⭐ CANDIDAT PRIORITAIRE

### Potentiel

9/10

### Idée

Paradoxe sur la progression aux échecs.

Le débutant/intermédiaire pense comprendre énormément.

En progressant, le joueur découvre surtout la quantité de choses qu'il ne comprend pas encore.

### Concept visuel

Deux joueurs / deux échiquiers :

**1200 ELO**
Confiance absolue.

**1800 ELO**
Confusion devant une position beaucoup plus complexe.

# 11. RÈGLES POUR LES VISUELS

## Priorité

Le design doit être pensé pour être IMPRIMÉ, pas simplement pour produire une belle image à l'écran.

## À privilégier

- silhouette claire ;
- contraste élevé ;
- sujet central identifiable ;
- texte lisible ;
- nombre limité d'éléments ;
- contours propres ;
- composition adaptée au torse ;
- fonctionnement sur textile noir et clair ;
- possibilité de fond transparent.

## À éviter

- arrière-plan photographique complet ;
- dizaines de petites pièces ;
- détails microscopiques ;
- ombres trop complexes ;
- texte généré directement dans une image IA sans contrôle ;
- éléments importants trop proches des bords.

# 12. LANGUES

## Priorité 1

🇪🇸 Espagnol

Chaque concept doit d'abord être évalué pour le marché espagnol.

## Priorité 2

🇫🇷 Français

Ne pas traduire mécaniquement.

La version française doit conserver :
- le jeu de mots ;
- le rythme ;
- l'humour ;
- la compréhension échiquéenne.

Certaines phrases pourront donc avoir une adaptation différente plutôt qu'une traduction littérale.

---

# 13. PRINCIPE DE SÉLECTION

Ne pas produire un design uniquement parce qu'une phrase est correcte.

Une phrase passe en production si elle réunit suffisamment de critères :

1. comprise rapidement ;
2. spécifique aux joueurs d'échecs ;
3. amusante ou identifiable ;
4. suffisamment courte pour un vêtement ;
5. permet un visuel fort ;
6. fonctionne en espagnol ;
7. n'est pas une phrase générique déjà vue partout ;
8. ne présente pas de problème juridique évident ;
9. peut fonctionner sur plusieurs produits ;
10. correspond à l'identité Peón Valiente.
